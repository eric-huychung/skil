# Build Phase Skills

Skills for implementation and code development.

## Available Skills

### increment
Delivers changes incrementally in thin vertical slices. Each increment is implemented, tested, verified, and committed before moving to the next. Use for any multi-file feature or change.

## Philosophy References

Build phase follows test-driven development (TDD) from `.cursor/skills/philosophy/tdd/` and references deep module design principles from `.cursor/skills/design/codebase-design/`.

## Usage

Access via `/build` command or read skills directly.
