# Design Phase Skills

Skills for mapping requirements to system design, architecture, and implementation tasks.

## Available Skills

### codebase-design
Deep module design principles - interface depth, seams, adapters, leverage and locality. Use when designing module boundaries, deciding interface shape, or improving testability.

### to-tasks
Breaks architecture documents into ordered, implementable tasks with acceptance criteria, dependencies, and verification steps. Use after architecture is defined.

## Usage

Access via `/design` command or read skills directly.
