# Productivity Skills

General-purpose tools that accelerate development work.

## Available Skills

### diagram-maker
Create SVG/HTML or Excalidraw diagrams for concepts, architecture, flows, and whiteboards. Choose between clean SVG, architecture SVG, or editable Excalidraw formats.

### git-workflow
Commit, branch, and version discipline. Use on every code change: atomic commits, short-lived branches, tags, and changelogs. Referenced from `/build` and `/deploy`.

### git-guardrail
Block dangerous git commands (push, reset --hard, clean, branch -D) before they run. Optional setup; referenced from `/build` and `/deploy`.

## Usage

Access directly, via `/design` (diagrams), `/build` (git-workflow, optional git-guardrail), or `/deploy` (versioning + git safety).
