# Testing Phase Skills

Skills for QA and validation.

## Available Skills

### debug
Diagnosis loop for hard bugs and performance regressions. Build tight feedback loops, minimize repro, hypothesize, instrument, fix, and add regression tests. Use when diagnosing broken/failing/slow code.

### refactor
Scans a codebase for deepening opportunities (shallow modules, leaky seams, untestable code), presents them as a visual HTML report, then walks through whichever candidate the user picks. Builds on `.cursor/skills/design/codebase-design/`.

## Usage

Access via `/testing` command or read skill directly.
