One flow, from scattered files to a shared playbook

Skil doesn't invent a new format. It reads what your agents already use and gives it structure.

  1. 01

    Connect a repo

    Point Skil at a local project folder. No account, no OAuth, nothing to sign into.

  2. 02

    Scan

    It reads .cursor, .claude, .windsurf, and .agents and lists every skill it finds.

  3. 03

    Organize

    Group skills under the SDLC commands you use — planning, build, testing, review.

  4. 04

    Export

    Write the organized set back to the repo. Additive by default, with a warning before anything is overwritten.

Built to stay out of your way

No login required

Point Skil at a folder and start. There is no account to create.

Additive by default

Exports add files and warn before overwriting anything you already have.

Organized by SDLC stage

Skills sit under the commands that use them, and commands sit under the stage they belong to.

Re-scan anytime

Refresh the view after editing the repo. It is a re-scan, not a live merge — you stay in control.

Also on the command line

Prefer the terminal? There's a CLI for that

The same scan, organize, and export flow, scriptable for CI or a pre-commit hook. Everything the desktop app does, headless.

  • No login or API key — it reads your local repo.
  • Additive exports with a warning before overwrite.
  • File skills onto commands so the map stays yours.
zsh — skil 

# Install the CLI with Homebrew
$brew install skil
# Scan the current repo for skills
$skil scan
✓ Found 52 skills across 4 sources
# Export a command to your IDE
$skil export build --to cursor
✓ Wrote .cursor/commands/build.md
